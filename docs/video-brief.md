## 3. 分鏡

兩支片的逐段分鏡表在各自劇本的 §3.5，含每一段的起訖時間與該錄什麼。
**時間碼以 .srt 為準**，廠商請把畫面對齊字幕，不要反過來要求改字幕秒數。

需要特別注意的三格：

1. **A 片 0:38–1:37（拔插頭）佔全片一半**，不要為了節奏平均而剪短。
   其中「成績只用刷卡的時間」這句字幕，必須壓在畫面上兩個時間戳出現的那一秒。
2. **B 片 1:10–1:23（暫停）不可剪接**。觀眾要看到時鐘數字連續三秒不動，
   剪過就失去意義。
3. 終端機畫面請放大到**在手機上讀得清楚**，必要時局部放大。

## 9. 已有的粗剪

`design/demo/record.py` 會真的跑一次系統、逐格截真實畫面、貼上字卡、配上背景音樂，
產出 3 分 16 秒的 1080p 影片（`design/demo/out/`）。**這是粗剪，不是成品**：每一格是靜態截圖加上緩慢推近
（Ken Burns，5% 以內、方向交替）與字卡淡入，沒有真正的操作錄影、沒有轉場。

```bash
cargo run -p hub-server &                                 # 另一個終端機
HYROX_DB_FILE=hyrox.db python3 design/demo/record.py overview
```

四段：賽制設定 → 比賽過程 → 課程規劃 → 課程執行。字是**貼在畫面上的**
（左下角字卡，46px），不是 .srt 外掛字幕 —— 投影機和手機上都讀得到。
`captions.py` 仍會輸出 .srt 給無字幕版本用。

它的用途有兩個：一是證明畫面上的每個數字都是真的跑出來的；二是給廠商當**分鏡參考**——
每一格該出現什麼，看粗剪比看文字快。
